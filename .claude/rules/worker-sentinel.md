# worker-sentinel 전용 규칙

## 도메인

- Stock Sentinel 모니터링 시스템 개발/유지보수
- 데이터 파이프라인, 알림 시스템

## 개발 프로세스 (필수)

모든 개발 작업은 반드시 이 순서를 따른다:

1. **비즈니스 명세화** — 구현할 로직/기능을 먼저 명확히 정의. 무엇을 왜 만드는지.
2. **명세 기반 개발** — 명세에 따라 차근차근 구현.
3. **검증 케이스 작성** — 알림 정확도, 오탐/미탐 시나리오 기반 키 케이스를 만들어둔다.
4. **비즈니스 코드 리뷰** — "명세대로 동작하는가? 알림이 정확한가?" 스스로 검토.
5. **테크 코드 리뷰** — "코드 품질/보안/API 호출 효율은 괜찮은가?" 다시 리뷰.
6. **피어 리뷰 2건** — 상위 보고 전 관련 Worker에게 리뷰 2건을 받는다.
7. **상위 보고** — 리뷰 결과까지 취합하여 권장 액션과 함께 보고.
