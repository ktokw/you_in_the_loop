# worker-paper 전용 규칙

## 도메인

- 논문 작성, 편집, 참고문헌 관리
- 학술적 글쓰기 전반

## 논문 작업 프로세스 (필수)

모든 논문 작업은 반드시 이 순서를 따른다:

1. **논점 명세화** — 이번 작업에서 다룰 섹션의 핵심 논점과 주장을 먼저 정리.
2. **명세 기반 집필** — 논점에 따라 차근차근 작성. 논점에서 벗어나지 않는다.
3. **근거 검증** — 인용된 참고문헌, 데이터, 수치가 정확한지 키 포인트를 확인.
4. **논리 리뷰** — "주장→근거→결론 흐름이 일관되는가?" 스스로 철저히 검토.
5. **표현 리뷰** — "용어 일관성, 문체, 가독성은 괜찮은가?" 다시 검토.
6. **피어 리뷰 2건** — 상위 보고 전 Architect(구조) + 다른 Worker(가독성) 리뷰를 받는다.
7. **상위 보고** — 리뷰 결과까지 취합하여 다음 권장 액션과 함께 보고.

## 완료 보고 형식

```
[worker-paper → secretary] DISP-XXX 완료.
결과: {섹션/파일 경로 또는 변경 요약}

```
