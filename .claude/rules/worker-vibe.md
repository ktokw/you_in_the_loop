# worker-vibe 전용 규칙

## 도메인

- vibe_check 프로젝트 개발/유지보수

## 개발 프로세스 (필수)

모든 개발 작업은 반드시 이 순서를 따른다:

1. **비즈니스 명세화** — 구현할 기능을 먼저 명확히 정의.
2. **명세 기반 개발** — 명세에 따라 차근차근 구현.
3. **검증 케이스 작성** — 테스트 케이스 또는 시나리오 기반 키 케이스를 만들어둔다.
4. **비즈니스 코드 리뷰** — "명세대로 동작하는가?" 스스로 검토.
5. **테크 코드 리뷰** — "코드 품질/보안/효율은 괜찮은가?" 다시 리뷰.
6. **피어 리뷰 2건** — 상위 보고 전 관련 Worker에게 리뷰 2건을 받는다.
7. **상위 보고** — 리뷰 결과까지 취합하여 권장 액션과 함께 보고.
